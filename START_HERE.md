# 🚀 COMECE AQUI

Bem-vindo ao **CRM Financeiro**! 👋

Seu projeto está **100% pronto**. Aqui está tudo que você precisa fazer para começar:

---

## ⚡ Passo 1: Instalar (2 min)

```bash
cd C:\Users\SERAFIM\Desktop\crm-financeiro
npm install
```

## ⚡ Passo 2: Configurar Supabase (5 min)

1. Vá para [supabase.com](https://supabase.com) e crie conta
2. Crie um novo projeto
3. Copie as chaves em **Settings → API**
4. Abra `.env.local` e preencha:
```
NEXT_PUBLIC_SUPABASE_URL=cole_aqui_a_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=cole_aqui_a_chave
```

## ⚡ Passo 3: Rodar Localmente (1 min)

```bash
npm run dev
```

Pronto! Acesse: http://localhost:3000

## 💡 Quick Tips

**Testar Localmente:**
```bash
npm run dev
# http://localhost:3000
```

**Build para Produção:**
```bash
npm run build
npm run start
```

**Fazer Push no GitHub:**
```bash
git remote add origin https://github.com/seu-usuario/crm-financeiro.git
git push -u origin main
```

**Deploy no Vercel:**
1. Conecte seu repositório GitHub no Vercel
2. Configure as variáveis de ambiente
3. Deploy automático! 🚀

## 🆘 Erro Comum?

**"Missing environment variables"**
→ Copie `.env.local.example` para `.env.local` e preencha as chaves

**"Página em branco"**
→ Abra DevTools (F12) e verifique console

**"Supabase connection failed"**
→ Verifique se as chaves estão corretas e internet está conectada
