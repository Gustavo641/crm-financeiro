## 🚀 Próximos Passos

### 1️⃣ Setup Supabase (5 minutos)

#### A. Criar projeto Supabase
1. Acesse [supabase.com](https://supabase.com)
2. Clique em "Start your project"
3. Faça login/cadastro
4. Crie um novo projeto:
   - **Project name**: `crm-financeiro`
   - **Database password**: Gere uma senha segura
   - **Region**: `South America (São Paulo)` (para menor latência)

#### B. Configurar variáveis de ambiente
1. Após criar o projeto, vá para **Settings → API**
2. Copie:
   - `Project URL` → `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public key` → `NEXT_PUBLIC_SUPABASE_ANON_KEY`

3. Edite `.env.local` na raiz do projeto:
```bash
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJxx.xxxxxx
```

#### C. Criar tabelas (SQL)
No Supabase, vá para **SQL Editor** e execute:

```sql
-- Users (gerenciado automaticamente pelo Auth)
-- Receitas
CREATE TABLE receitas (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  user_id UUID NOT NULL REFERENCES auth.users(id),
  descricao TEXT NOT NULL,
  valor DECIMAL(10, 2) NOT NULL,
  data DATE NOT NULL,
  categoria TEXT NOT NULL,
  banco TEXT,
  status TEXT DEFAULT 'pendente',
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Despesas
CREATE TABLE despesas (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  user_id UUID NOT NULL REFERENCES auth.users(id),
  descricao TEXT NOT NULL,
  valor DECIMAL(10, 2) NOT NULL,
  data DATE NOT NULL,
  categoria TEXT NOT NULL,
  forma_pagamento TEXT,
  banco TEXT,
  status TEXT DEFAULT 'pendente',
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Metas
CREATE TABLE metas (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  user_id UUID NOT NULL REFERENCES auth.users(id),
  nome TEXT NOT NULL,
  valor_desejado DECIMAL(10, 2) NOT NULL,
  valor_atual DECIMAL(10, 2) DEFAULT 0,
  data_alvo DATE,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Contas (bancos)
CREATE TABLE contas (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  user_id UUID NOT NULL REFERENCES auth.users(id),
  nome TEXT NOT NULL,
  saldo DECIMAL(10, 2) DEFAULT 0,
  tipo TEXT,
  status TEXT DEFAULT 'ativo',
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Cartões
CREATE TABLE cartoes (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  user_id UUID NOT NULL REFERENCES auth.users(id),
  nome TEXT NOT NULL,
  numero_final TEXT,
  limite DECIMAL(10, 2),
  utilizado DECIMAL(10, 2) DEFAULT 0,
  fechamento TEXT,
  vencimento TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Logins (criptografado)
CREATE TABLE logins (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  user_id UUID NOT NULL REFERENCES auth.users(id),
  site TEXT NOT NULL,
  usuario TEXT NOT NULL,
  senha_criptografada TEXT NOT NULL,
  categoria TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Ativar RLS (Row Level Security)
ALTER TABLE receitas ENABLE ROW LEVEL SECURITY;
ALTER TABLE despesas ENABLE ROW LEVEL SECURITY;
ALTER TABLE metas ENABLE ROW LEVEL SECURITY;
ALTER TABLE contas ENABLE ROW LEVEL SECURITY;
ALTER TABLE cartoes ENABLE ROW LEVEL SECURITY;
ALTER TABLE logins ENABLE ROW LEVEL SECURITY;

-- Criar políticas RLS
CREATE POLICY receitas_users_access ON receitas
  FOR ALL USING (auth.uid() = user_id);

CREATE POLICY despesas_users_access ON despesas
  FOR ALL USING (auth.uid() = user_id);

CREATE POLICY metas_users_access ON metas
  FOR ALL USING (auth.uid() = user_id);

CREATE POLICY contas_users_access ON contas
  FOR ALL USING (auth.uid() = user_id);

CREATE POLICY cartoes_users_access ON cartoes
  FOR ALL USING (auth.uid() = user_id);

CREATE POLICY logins_users_access ON logins
  FOR ALL USING (auth.uid() = user_id);
```

### 4️⃣ Deploy no Vercel (10 minutos)

#### A. Conectar GitHub
1. Faça push do código:
```bash
git remote add origin https://github.com/SEU_USUARIO/crm-financeiro.git
git branch -M main
git push -u origin main
```

#### B. Deploy
1. Acesse [vercel.com](https://vercel.com)
2. Clique "Import Project"
3. Selecione seu repositório `crm-financeiro`
4. Configure variáveis de ambiente:
   ```
   NEXT_PUBLIC_SUPABASE_URL = seu_valor
   NEXT_PUBLIC_SUPABASE_ANON_KEY = seu_valor
   ```
5. Clique "Deploy"

**Pronto!** Seu app estará em: `https://crm-financeiro.vercel.app`

## 🔧 Troubleshooting

**Erro: "Missing environment variables"**
- Copie `.env.local.example` para `.env.local`
- Preencha com suas credenciais do Supabase

**Erro: "Authentication failed"**
- Verifique se as chaves do Supabase estão corretas
- Confirme que o projeto Supabase está ativo

**Erro: "Database connection failed"**
- Verifique conexão com internet
- Confirme que o Supabase está respondendo (https://status.supabase.com)

**Página em branco**
- Abra DevTools (F12) e verifique console
- Execute `npm run build` para testar build
- Verifique se todas as dependências foram instaladas
